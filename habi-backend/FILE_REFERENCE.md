## ⚙️ Configuration Files

### package.json
**Defines:**
- Project metadata (name, version, description)
- Main entry point: server.js
- Module type: ES modules
- Scripts: start, dev, test
- Dependencies (10 packages)
- DevDependencies

**Edit this to:**
- Add/remove dependencies
- Modify scripts
- Change project info

### .env (Environment Variables)
**Contains:** (NEVER COMMIT THIS FILE)
```
PORT=5000
NODE_ENV=development
FIREBASE_PROJECT_ID=habits-64801
FIREBASE_PRIVATE_KEY=...
FIREBASE_CLIENT_EMAIL=...
```

### .env.example (Template)
Shows the structure of .env without sensitive values.
Share this with other developers so they know what to set up.

### .gitignore (Version Control Rules)
Tells Git which files to ignore:
```
node_modules/
.env
serviceaccountkey.json
*.log
.DS_Store
```

## 📖 How to Use These Files

### For Development
1. Edit **server.js** to modify API endpoints
2. Add validation in **utils.js** if needed
3. Run `npm run dev` to auto-reload changes
4. Use **test-api.js** to verify changes

### For Deployment
1. Create production **.env** with correct values
2. Run `npm install --production`
3. Start with `npm start`
4. Monitor logs for errors

### For Documentation
1. Keep **API.md** updated when adding endpoints
2. Update **DATABASE_SCHEMA.md** if data structure changes
3. Update **README.md** for setup changes
4. Keep **PROJECT_SUMMARY.md** current

### For Version Control
1. Always check `.gitignore` before committing
2. Never commit `.env` or `serviceaccountkey.json`
3. DO commit `package.json` and `package-lock.json`
4. Review what you're committing with `git status`

## 💡 Tips

1. **Before running:**
   - Make sure `.env` is present (copy from example if needed)
   - Run `npm install` first

2. **When debugging:**
   - Check server.js error handling
   - Look at error messages in console
   - Use test-api.js to isolate issues

3. **When adding features:**
   - Add new endpoint to server.js
   - Add validation logic to utils.js
   - Update API.md documentation
   - Add test case to test-api.js

4. **Before committing:**
   - Run `git status` to see changes
   - Make sure .env is NOT in the list
   - Verify package-lock.json includes your changes

## 🆘 Troubleshooting by File

| Issue | Check File | Fix |
|-------|-----------|-----|
| "Cannot find module 'express'" | package.json | Run `npm install` |
| "Firebase not initializing" | .env | Check credentials |
| "Port 5000 already in use" | server.js | Change PORT in .env |
| "Module not found" | server.js | Check import statements |
| "API endpoint 404" | API.md | Verify endpoint URL matches |
| "Test fails" | test-api.js | Check server is running |
